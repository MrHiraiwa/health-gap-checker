健康診断の実測値と日本の医学的推奨ターゲットの「ギャップ（あと何kg、あとどれくらい数値を落とすか）」を可視化し、健康リスクを抱える人でも安全に取り組める減量・生活習慣処方箋を自動算出するシングルページWebアプリケーションです。

🇯🇵 **日本の健診・医学ガイドラインに完全準拠**  
本ツールは、日本人間ドック学会、日本腎臓学会（日本人向けeGFR推算式）、日本肥満学会（BMI判定・学校保健ローレル指数）、日本高血圧学会等の国内ガイドラインをベースに設計されています。

## 🌟 主な特徴

### 1. 🎯 日本の医学的推奨値との「自動ギャップ分析」
- 健診数値を入力するだけで、国内各学会ガイドラインに基づいた推奨ターゲットとの差分を自動計算。
- 単なる「A〜E判定」にとどまらず、**目標値まであとどれくらい改善が必要か**を直感的に把握できます。

### 2. ⚡ 手軽にチェックできる「簡易モード」
- 血液検査の数値がまだ手元になくても、血圧や身長・体重だけでサクッと現在のギャップや推奨カロリーをチェックできる簡易入力モードを搭載。

### 3. 🎒 成人健診 / 未成年（学校健診・成長期）のワンタッチ切り替え
- 年齢やモード選択により、成人向けの血液検査・減量カロリー計算と、学校健診（視力・検尿所見・ローレル指数による発育評価）を自動切り替え。
- 成長期のお子様には大人のような減量指示を出さず、安全な発育チェックを行います。

### 4. 👗 目指す体型別の減量ターゲット（成人）
- **標準体重（BMI 22）**: 最も病気になりにくい健康基準
- **美容体重（BMI 20）**: スタイルがすっきり見える美容基準
- **モデル体重（BMI 18.5）**: スリム体型の安全下限基準
- 身長に応じた各体重目標までの過不足（kg）や達成期間のロードマップを算出します。

### 5. 🔥 基礎代謝・活動量に応じた推奨摂取カロリー
- Mifflin-St Jeor式と活動レベル（デスクワーク〜運動習慣）から「維持カロリー（TDEE）」「基礎代謝（BMR）」「減量推奨カロリー」を算出。
- 代謝を落とさない安全なアンダーカロリー設計を提示します。

### 6. ⚠️ 臓器別・健康リスクに応じた特別ダイエット処方箋
- **腎機能ケア中（日本人式低eGFR / 高クレアチニン）**: 過度な高タンパク食・プロテイン過剰を避け、減塩＆水分補給中心の安全な減量アプローチを提示。
- **高血圧**: いきむ筋トレを避け、有酸素運動＆カリウム・減塩指導。
- **肝機能高め（脂肪肝傾向）**: 極端な絶食を避け、夜間糖質カットと内臓脂肪燃焼アプローチ。
- **尿酸値高め**: 急激な絶食・激しい無酸素運動による尿酸値スパイクを防ぐ緩やかな減量・水分管理。

### 7. 🔒 完全ローカル処理（プライバシー安全設計）
- 入力データは**一切外部サーバーへ送信されません**。
- ブラウザのローカルストレージによる常時自動保存に加え、ページ最下部のボタンからJSON形式でのバックアップ（エクスポート）および復元（インポート）に対応。

### 8. 📄 印刷・A4 PDF出力対応
- 印刷用CSSを完備。「印刷 / PDF出力」ボタンから、入力フォームを除いた綺麗な診断レポートPDFをワンクリックで生成できます。
