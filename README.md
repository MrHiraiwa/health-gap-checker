健康診断の実測値と医学的推奨ターゲットの「ギャップ（あと何kg、あとどれくらい数値を落とすか）」を可視化し、健康リスクを抱える人でも安全に取り組める減量・生活習慣処方箋を自動算出するシングルページWebアプリケーションです。

---

## 🌟 主な特徴

### 1. 🎯 医学的推奨値との「自動ギャップ分析」
* 健診数値を入力するだけで、日本高血圧学会・動脈硬化学会・腎臓学会などのガイドラインに基づいた推奨ターゲットとの差分を自動計算。
* 「判定記号（A〜E）」をなぞるだけでなく、**目標値まであとどれくらい改善が必要か**を直感的に把握できます。

### 2. 👗 目指す体型別の減量ターゲット
* **標準体重（BMI 22）**: 最も病気になりにくい健康基準
* **美容体重（BMI 20）**: スタイルがすっきり見える美容基準
* **モデル体重（BMI 18.5）**: スリム体型の安全下限基準
* 身長に応じた各体重目標までの過不足（kg）を算出します。

### 3. 🔥 基礎代謝・活動量に応じた推奨摂取カロリー
* Mifflin-St Jeor式と活動レベル（デスクワーク〜運動習慣）から「維持カロリー（TDEE）」「基礎代謝（BMR）」「減量推奨カロリー」を算出。
* 代謝を落とさない安全なアンダーカロリー設計を提示します。

### 4. ⚠️ 臓器別・健康リスクに応じた特別ダイエット処方箋
* **腎機能ケア中（低eGFR / 高クレアチニン）**: 過度な高タンパク食・プロテイン過剰を避け、減塩＆水分補給中心の安全な減量アプローチを提示。
* **高血圧**: いきむ筋トレを避け、有酸素運動＆カリウム・減塩指導。
* **肝機能高め（脂肪肝傾向）**: 極端な絶食を避け、夜間糖質カットと内臓脂肪燃焼アプローチ。
* **尿酸値高め**: 急激な絶食・激しい無酸素運動による尿酸値スパイクを防ぐ緩やかな減量・水分管理。

### 5. 🎒 成人健診 / 未成年（学校健診）のワンタッチ切り替え
* 年齢やタブ選択により、一般健診項目と学校健診項目（視力・尿検査所見など）を自動で切り替えます。

### 6. 🔒 完全ローカル処理（プライバシー安全設計）
* 入力データは**一切外部サーバーへ送信されません**。
* ブラウザのローカルストレージ自動保存に加え、JSON形式でのバックアップ（エクスポート）および復元（インポート）に対応。

### 7. 📄 印刷・A4 PDF出力対応
* 印刷用CSSを完備。「印刷 / PDF出力」ボタンから、入力フォームを除いた綺麗な診断レポートPDFをワンクリックで生成できます。
