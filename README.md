健康診断の実測値と日本の医学的推奨ターゲットの「ギャップ（あと何kg、数値改善に必要な目標）」を可視化し、健康リスクを抱える人でも安全に取り組める減量・生活習慣処方箋を自動算出するシングルページWebアプリケーションです。

🇯🇵 **日本の健診・医学ガイドラインに完全準拠**  
本ツールは、日本人間ドック学会、日本腎臓学会（日本人向けeGFR推算式）、日本肥満学会（BMI判定・学校保健ローレル指数）、日本高血圧学会等の国内ガイドラインをベースに設計されています。

## 🌟 主な特徴

### 1. 🎯 体型目標（標準・美容・モデル）の「全同時比較シミュレーション」
- 面倒な目標選択の切り替えを排し、一回の分析で **標準体型 (BMI 22)**・**美容体型 (BMI 20)**・**モデル体型 (BMI 18.5)** の目標体重、過不足（kg）、推奨カロリーレンジ、達成予測期日（リアル日付）をカードグリッドで並べて同時比較します。

### 2. 📊 運動量に合わせた「カロリーレンジ（幅）表示」＆ PFCバランス
- 日によって変動する活動量（デスクワーク〜アクティブ）に対応し、維持カロリーおよび減量カロリーをビジュアルプログレスバーによる **レンジ（幅）** で提示。
- 基礎代謝（BMR）を下回らない安全なアンダーカロリー設計と、PFCバランス（タンパク質・脂質・炭水化物）の内訳を自動算出します。

### 3. 📈 Chart.js による「指数減衰＆年齢補正シミュレーショングラフ」
- **成人・自宅モード**: 目標体重に近づくにつれて変化が緩やかになる医学的・生理学的に自然な「指数減衰モデル」を算出し、実際の経過日付（リアル日程）付きでグラフ描画。
- **未成年（成長期）モード**: 年齢に応じた年間成長量モデル（学童期・スパート期・減速期）を自動判別し、**「身長成長曲線」×「現在の体重キープ線」×「適正体重目安線」** の2軸グラフを描画。成長期に無理な減量をさせず、身長の伸びで自然に標準化されるプロセスを提示します。

### 4. ⚠️ 臓器別・健康リスクに応じた特別ダイエット処方箋
- **腎機能ケア中（日本人式低eGFR / 高クレアチニン）**: 過度な高タンパク食・プロテイン過剰を避け、減塩＆水分補給中心のアプローチを提示。
- **高血圧**: いきむ筋トレを避け、有酸素運動＆カリウム・減塩指導。
- **肝機能高め（脂肪肝傾向）**: 極端な絶食を避け、夜間糖質カットと内臓脂肪燃焼アプローチ。
- **尿酸値高め**: 急激な絶食・激しい無酸素運動による痛風発作を防ぐ緩やかな減量・水分管理。

### 5. 🎒 成人健診 / 自宅計測 / 未成年（学校健診・成長期）のワンタッチ切り替え
- **成人健診モード**: 血液検査フル対応・各種ギャップ分析。
- **自宅計測モード**: 体重・血圧のみでサクッと手軽にチェック。
- **未成年モード**: 視力・学校検尿（タンパク/糖）・ローレル指数による発育評価。

### 6. 🔒 完全ローカル処理（プライバシー安全設計＆ローカルライブラリ完結）
- 入力データは **一切外部サーバーへ送信されません**。すべて端末内・ブラウザ内のみで計算・自動保存されます。
- `Chart.js` ファイル（`chart.umd.min.js`）も同階層にローカル配置することで、完全オフライン環境下でも安全に全機能が動作します。
- JSON形式によるデータのバックアップ（エクスポート）および復元（インポート）に対応。

### 7. 📄 印刷・A4 PDF出力対応
- 印刷専用CSSを完備。「印刷 / PDF出力」ボタンから、入力フォームを除いた綺麗なレポートPDFを生成可能。数値を伏せるプライバシー出力にも対応しています。
